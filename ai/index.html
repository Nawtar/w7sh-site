استخدم W7SH مع مساعد ذكاء اصطناعي

قريبًا: الخادم لم يُنشر بعد، وهذه الصفحة تشرح كيف سيعمل.

ما هو

خادم MCP صغير يعمل على حاسوبك ويقرأ ملف التصدير الخاص بك من W7SH، ليتمكن Claude Desktop أو أي برنامج يدعم MCP من الإجابة عن أسئلة مثل «كيف تطوّر بنشي في الشهرين الأخيرين؟» أو «أي عضلة أدربها أقل من غيرها؟».

خصوصيتك

  • للقراءة فقط: لا يغيّر شيئًا في ملفك ولا في حسابك.
  • بلا إنترنت وبلا حساب: يقرأ الملف من حاسوبك فقط ولا يرسله إلى W7SH ولا إلى غيرها.
  • المساعد الذي تستخدمه يرى ما يطلبه من الأرقام، وتسري عليه شروط ذلك المساعد.

١. صدّر بياناتك

في W7SH: حسابي ← الإعدادات ← تصدير بياناتي ← JSON، ثم احفظ الملف على حاسوبك. تحتاج إلى تفعيل المزامنة ليصل الملف إلى تمارينك كلها.

٢. أضف الخادم إلى Claude Desktop

افتح Claude Desktop ← الإعدادات ← المطوّر ← تعديل الإعدادات، وضع هذا في الملف مع مسار ملفك أنت، ثم أعد تشغيل Claude. يحتاج حاسوبك إلى Node.js بإصدار 20 أو أحدث.

{
  "mcpServers": {
    "w7sh": {
      "command": "npx",
      "args": ["-y", "w7sh-mcp", "/Users/you/Downloads/w7sh-2026-10-13.json"]
    }
  }
}

٣. اسأل

  • جرّب: «لخّص تمريني في آخر أربعة أسابيع»، «أرني تاريخ السكوات»، «ما أرقامي الشخصية؟»، «كم جولة أدرب للظهر في الأسبوع؟».
  • الأوزان بوحدتك في W7SH، وأسماء التمارين بالعربية والإنجليزية.
  • للحصول على أرقام أحدث صدّر الملف من جديد وأعد تشغيل Claude.
