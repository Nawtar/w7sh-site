Use W7SH with an AI assistant

What it is

A small MCP server that runs on your computer and reads your own W7SH export, so Claude Desktop or any MCP client can answer questions like "How has my bench moved in the last two months?" or "Which muscle am I training least?"

Your privacy

  • Read-only: it changes nothing in your file or your account.
  • No network and no account: it reads the file on your computer and sends it nowhere, not to W7SH and not to anyone else.
  • The assistant you use sees the numbers it asks for, under that assistant’s own terms.

1. Export your data

In W7SH: Profile → Settings → Export my data → JSON, then save the file on your computer. Turn sync on so the file has all your training.

2. Add the server to Claude Desktop

Open Claude Desktop → Settings → Developer → Edit Config, put this in the file with the path to your own export, and restart Claude. Your computer needs Node.js 20 or newer.

{
  "mcpServers": {
    "w7sh": {
      "command": "npx",
      "args": ["-y", "w7sh-mcp", "/Users/you/Downloads/w7sh-2026-10-13.json"]
    }
  }
}

3. Ask

  • Try: "Sum up my last four weeks", "Show my squat history", "What are my personal records?", "How many sets a week do I do for back?"
  • Weights come in your W7SH unit, exercise names in Arabic and English.
  • For newer numbers, export again and restart Claude.
